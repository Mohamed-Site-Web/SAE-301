# SAE-301

## Pour pouvoir envoyé vos modifs

Etape 1 : Ouvrir "Controle de code source" Sur la barre vertical à gauche sur VSCode

Etape 2 : Puis, TOUJOURS cliquer sur "Synchroniser les modifications" (Ca permet d'avoir à jour notre espace et de voir les dernieres modification).

Etape 3 : Faite vos modifs et CTRL S ensuite (IMPERATIVE)

Etape 4 : Dans changement vous devez voir le document modifier, cliquer donc sur le "+"

Etape 5 : Dans la case message écrire ce que vous avez modifs 

Etape 6 : Cliquer sur le bouton "Validation"

Etape 7 : Enfin cliquer sur le bouton qui à remplacer validation 

Etape 8 : GG vous avez reussi à réaliser un tuto simple !!!!
